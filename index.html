03 / Narrow the options

Staged filtering

A transparent screening sequence: each stage shows what remains and what is eliminated.

Filtering flow

This dashboard uses a consistent staged screen: (1) retain alternatives tied for the highest Maximin value; (2) among those, retain alternatives tied for the lowest maximum regret; (3) among those, retain alternatives tied for the highest EMV. If probabilities are invalid, the final stage is paused. This is a transparent comparison workflow, not a separate universal decision rule.
